**Project Title:**

MediSphere - Doctor Appointment Booking Platform



**Project Description:**

MediSphere is a multi-page web application built using ReactJS that streamlines the process of scheduling and managing doctor appointments. 

Currently designed just for patients. 

The platform provides a user-friendly interface for discovering medical professionals, checking availability, booking appointments, and managing health consultations online.

The project is structured as a multi-page application using React Router to handle navigation across various sections such as 

Home, Doctor Listings, Appointment Booking, Login/Signup, About Us and Contact Us along with Patient Profile and list of appointments scheduled.

Each page is modularly developed using React components to maintain clean and scalable code architecture.



**Key Features:**

User Authentication: Secure login/signup for patients and doctors.

Doctor Directory: Browse and search doctors by specialization and availability.

Appointment Booking: Select preferred doctor, date, and time for appointments (within 7 days window).

Responsive Design: Optimized for mobile, tablet, and desktop views.

State Management: React hooks and context API used for efficient state handling.

Routing: Implemented using react-router-dom for seamless navigation across multiple pages.



**Technology Stack:**

Frontend Framework: ReactJS

Routing: React Router

State Management: React Hooks, Context API

Styling: TailwindCSS 

Data Integration: Custom data with limited amount of information (as of now)

Other library: React Toastify (for adding sleek and non-intrusive notifications)
